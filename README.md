# Curso IA Doctorandos UFV

Repositorio web estático para GitHub Pages.

## Publicación en GitHub Pages

1. Crear un repositorio en GitHub.
2. Subir estos archivos a la raíz del repositorio.
3. Ir a Settings → Pages.
4. En "Build and deployment", seleccionar:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
5. Guardar.

La web quedará publicada en una URL tipo:
https://USUARIO.github.io/NOMBRE-REPOSITORIO/
