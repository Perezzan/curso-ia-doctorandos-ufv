# Despliegue en Netlify

Esta web es estática. Para publicarla basta con subir esta carpeta a Netlify.

## Opción rápida
1. Entrar en Netlify.
2. Crear nuevo sitio desde carpeta/proyecto.
3. Publicar la carpeta `proyectos/repositorio-prompts-curso`.
4. Compartir la URL pública o generar QR con esa URL.

## Archivos principales
- `index.html`: estructura de la página.
- `styles.css`: diseño visual.
- `prompts.js`: listado editable de prompts.
- `app.js`: buscador, filtros, expansión y copiar al portapapeles.
- `netlify.toml`: configuración mínima para Netlify.
